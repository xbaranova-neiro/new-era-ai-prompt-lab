# Сильный промпт — Новая эра ИИ

Домашняя практика первого дня курса. Участник выбирает одну задачу, тренируется на связанном примере и собирает запрос для себя. Ориентир — около 10 минут.

1. Выбрать задачу: пост, ответ клиенту, план или объяснение темы. Если своей задачи нет, можно взять готовый пример.
2. Дважды улучшить один учебный пример. На экране видны исходный запрос и ответ. Участник находит проблему, выбирает уточнение и сравнивает «было / стало». Ошибки сопровождаются объяснением и не блокируют продолжение. Верный ответ нельзя определить по длине.
3. Ответить на три коротких вопроса — по одному на экране. Можно нажимать на готовые примеры или писать своё. Поля и итоговый запрос зависят от выбранной задачи.

В финале сразу появляется поздравление «Домашка выполнена» и готовый запрос с копированием. Переход в ChatGPT и дополнительная проверка ответа в стороннем сервисе не требуются. Сдача домашки через форму и заявка на обучение — отдельные действия. Страница не заявляет, что домашка уже принята.
Прогресс каждой задачи сохраняется в браузере. Можно вернуться назад и изменить ответы. Заблокированное хранилище не мешает прохождению, но без него прогресс не сохраняется.

Учебные ответы заранее подготовлены и подписаны как примеры. Генерация ИИ внутри сайта не подключена.

Для подключения форм задайте `HOMEWORK_URL` (сдача домашки) и `APPLICATION_URL` (заявка на обучение) в `index.html`. Пока владелец не передал реальные HTTPS-ссылки, соответствующие блоки скрыты. Почтовых ссылок и неработающих кнопок нет. Переход в форму не меняет статус на «принято». Заявка на обучение необязательна.

Сайт статический: откройте `index.html` или запустите `python3 -m http.server`. Проверки логики: `node tests/homework.test.cjs`.
