# Сильный промпт — Новая эра ИИ

Интерактивная практика первого дня курса. Участник проходит три коротких задания без длинного набора текста:

1. Выбирает аудиторию, цель и формат — тренажёр сам усиливает слабый запрос.
2. Выбирает три исправления и получает готовый промпт без противоречий и выдуманных данных.
3. Отвечает кнопками на простые вопросы и вводит только название своей темы или продукта.

На каждом шаге доступно автозаполнение. В финале промпт можно скопировать, открыть в ChatGPT или перейти к заявке на курс.
