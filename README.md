# Сильный промпт — Новая эра ИИ

Интерактивная практика первого дня курса: три задания, подсказки по ходу работы и готовый промпт для собственной задачи.

1. Усиль слабый запрос.
2. Найди противоречия и исправь запрос.
3. Собери промпт для своей задачи и скопируй результат.

Откройте `index.html` в браузере. Сайт не требует сборки или сервера: изображения и шрифты лежат рядом с ним, а ответы сохраняются в браузере. Проверка заданий работает по локальным критериям без внешнего API.
