# Сильный промпт — Новая эра ИИ

Практика первого дня курса: понять принцип, применить его на примере и собрать запрос для своей задачи. Ориентир по времени — 10–15 минут.

1. Пять вопросов с объяснениями. Достаточно одного варианта; остальные три доступны для дополнительной практики. Ошибки не блокируют переход, а в памятке раскрывается разбор неверных ответов.
2. Три последовательных улучшения одного запроса: аудитория, формат и факты. После них — два заранее подготовленных учебных ответа для сравнения и вопрос на понимание.
3. Четыре ответа: задача, тема, аудитория и цель. Формат и доступные цели соответствуют задаче: пост, контент-план или описание продукта. Есть готовый пример и возможность указать свою аудиторию.

В финале: готовый запрос, копирование, ссылка на ChatGPT, три критерия проверки ответа и готовые уточнения. Кнопка заявки открывает почтовое приложение с адресом школы.

Прогресс сохраняется в браузере. Учебное сравнение — подготовленные примеры, а не генерация ИИ. Подключение к модели и отправка заявок через сервер не используются.
